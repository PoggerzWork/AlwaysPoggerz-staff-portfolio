# AlwaysPoggerz — Minecraft Staff Portfolio

A free, responsive, single-page portfolio website with a dark purple Solo Leveling-inspired visual style and Minecraft-inspired block character. The character is a CSS illustration placeholder, not an official Minecraft skin or copyrighted anime art.

## View it locally

Extract the ZIP and open `index.html` in Chrome, Safari, Edge or Firefox. Internet is not needed to view the site. The external Discord invite links will require internet.

## Publish for FREE using GitHub Pages

1. Sign into https://github.com (a free account is enough).
2. Click **+** → **New repository**.
3. Name the repository `alwayspoggerz-portfolio` (or any name you like). Choose **Public** and **Create repository**.
4. Choose **uploading an existing file** (or **Add file → Upload files**).
5. **Upload the contents of this extracted folder**, including `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder. Do not upload only the ZIP, and do not nest the files inside another folder. `index.html` must be at the repository root.
6. Click **Commit changes**.
7. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**. Choose **main** and **/(root)**, then **Save**.
8. After GitHub finishes deploying, open `https://YOUR-GITHUB-USERNAME.github.io/alwayspoggerz-portfolio/` (replace `YOUR-GITHUB-USERNAME` with your actual GitHub username). If you used a different repository name, replace the path as well. GitHub Pages can take a few minutes to become available.

This setup requires **no domain purchase, no hosting bill, no framework, no npm install, and no API keys**. GitHub Pages is free for public repositories. The repository's content is public, so don't upload private information.

## Customize

- **Words and links:** edit `index.html` in a text editor or directly on GitHub.
- **Colors/layout:** edit `styles.css`.
- **Menu and copy button:** edit `script.js`.
- **Add screenshots:** put files in `assets/` and insert, for example, `<img src="assets/my-screenshot.png" alt="Staff management screenshot" loading="lazy">` into `index.html`. Remove usernames, IDs or private staff conversations from screenshots first.
- **Replace placeholder art:** add a picture to `assets/` and replace the `.hero-art` section in `index.html` with an image. Add CSS to style the image. Ensure you have rights to the picture.

## Notes

- Email and real name are intentionally not displayed.
- The Discord contact button copies `AlwaysPoggerz`. If clipboard access is blocked when opened as a local file, the button shows the username for manual copying. Clipboard should work on GitHub Pages over HTTPS.
- Discord invite links can expire or change. Update them in `index.html` as needed.
- The site does not collect data, use trackers or send form submissions.
